# SosedShare — Сервис P2P-шеринга вещей и инструментов

Веб-приложение сервиса добрососедской аренды «SosedShare», разработанное в рамках дисциплины «Разработка мобильно-ориентированных приложений».

## О проекте
- **Целевая аудитория**: Жители многоквартирных домов и районов, желающие брать или сдавать в аренду бытовую технику, электроинструмент, спортивный инвентарь и настольные игры.
- **Архитектура**: Mobile First, адаптивная верстка HTML5/CSS3 (Flexbox, CSS Grid), адаптация под десктопы и планшеты.
- **Интеграция**: Приложение подготовлено для запуска внутри нативной оболочки гибридного мобильного приложения (React Native / Expo WebView).

## Структура репозитория
- `index.html` — Главная страница каталога с фильтрами по радиусу и категориям;
- `details.html` — Экран подробного описания товара (перфоратор/дрель Bosch) с формой бронирования;
- `profile.html` — Личный кабинет пользователя и панель управления объявлениями;
- `css/normalize.css` — Сброс и нормализация браузерных стилей;
- `css/style.css` — Основные стили проекта по методологии Mobile First;
- `js/app.js` — Интерактивный функционал (гамбургер-меню, модальные окна, фильтрация);
- `assets/images/` — Графические ресурсы, иконки и фотографии товаров.
